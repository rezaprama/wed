# Security

Do not put credentials, guestbook exports, private guest data or personal photographs in a public issue.

Report a vulnerability through [GitHub private vulnerability reporting](https://github.com/rezaprama/wed/security/advisories/new). Include affected version, reproduction steps with sample data, and impact. Do not include a live token. If private reporting is unavailable, open a public issue asking for a private contact without describing the vulnerability itself.

The current main branch is supported. New wishes are moderated before publication. Optional admin tokens are server-validated, stay in browser memory and must be kept in Cloudflare secrets or ignored local `.dev.vars` files. `noindex` is not access control. A private source repository does not make the deployed website private.
